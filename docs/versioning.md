# バージョン番号の方針

現在の公開バージョンは **1.17.2**。内部ビルド番号は **28**。

過去のリリースタグがないため、以下は実際の公開履歴ではなく、初期実装を
1.0.0、各コミットを仮のリリース単位として変更内容から復元した採番である。
コミット数をそのままバージョンに変換したものではない。

- メジャー：既存の保存データや利用方法の互換性を壊す変更。
- マイナー：既存機能と互換性のある利用者向け機能追加。パッチは0に戻す。
- パッチ：既存機能の不具合修正や操作・表示の調整。
- 同じ単位に複数の変更がある場合、最も大きい区分を1回適用する。
- 内部整理、テスト、CI、文書だけの変更では公開バージョンを上げない。

## 今後の更新

この復元番号を基準に、今後はリリース単位で採番する。コミットごとには上げない。
例えば次のリリースが修正のみなら1.17.3、機能追加を含めば1.18.0、
互換性を壊す変更を含めば2.0.0とする。
アプリとウィジェットの公開バージョン・ビルド番号は揃える。
