# 法的ドキュメントとリリース準備メモ

このフォルダには，App Store公開に必要な法的文書と提出時の注意事項をまとめています．

## 含まれるもの

- `privacy-policy.md` — プライバシーポリシー（公開URLが必須）
- `terms-of-use.md` — 利用規約・免責事項
- アプリ内の同内容画面: 設定 ＞ アプリについて（プライバシーポリシー／利用規約／ライセンス）

## 公開前に必ず差し替えるプレースホルダ

以下は仮置きです．実値に置き換えてください（アプリ内・Markdownの両方）．

| プレースホルダ | 差し替え先 | 該当箇所 |
| --- | --- | --- |
| `（開発者名）` | 開発者・提供者名 | `AppMetadata.developerName`，本フォルダのMarkdown |
| `（連絡先メール）` | 問い合わせ先メール等 | `AppMetadata.contactEmail`，本フォルダのMarkdown |

## プライバシーポリシーの公開（URLが必要）

App Store Connect では「プライバシーポリシーURL」が必須です．`privacy-policy.md` を公開Webページにして，そのURLを登録してください．例:

- GitHub Pages: リポジトリの `docs/` を Pages のソースに設定すると `https://<ユーザー名>.github.io/<リポジトリ>/legal/privacy-policy` 等で公開できます．
- もしくは Gist / Notion 公開ページ / 任意のホスティング．

## App Store Connect「App のプライバシー」回答の目安

本アプリは開発者・第三者へデータを送信しません（解析・広告なし．認証情報は端末内キーチェーン限定，学修データは利用者自身のiCloud）．そのため基本は **「データを収集していません（Data Not Collected）」** で回答できます．

- 位置情報: 端末内処理＋Appleの経路計算に渡すのみ（開発者は収集しない）．
- 認証情報: 利用者本人が大学/manabaへログインする送信のみ（開発者は収集しない）．
- 入力内容を最終的に判断するのは申請者です．不安な場合はAppleの定義（「収集」＝開発者のサーバー等へ送信・保持）を確認してください．

## 書き出し規制（暗号）

`Info.plist` に `ITSAppUsesNonExemptEncryption = false` を設定済みです（標準的なHTTPSとTOTP用HMACのみで，適用除外に該当）．これによりアップロードごとの輸出コンプライアンス入力が不要になります．

## ⚠️ 重要: App Store審査リスク（ガイドライン 5.2.2）

本アプリは利用者の大学アカウントで**ポータル／manabaへ自動ログイン・情報取得**を行います．Appleのガイドライン **5.2.2**（第三者サービスのコンテンツ利用には，そのサービスの規約上の許諾が必要）に抵触する恐れがあり，**一般公開は却下・公開停止のリスク**があります．

- 千葉工業大学・朝日ネットが第三者アプリの自動ログインを許可している可能性は低い点に留意してください．
- 公開前に各サービスの利用規約を確認し，必要であれば許諾の取得や，連携機能の扱い（任意機能化・公開範囲の限定）を検討してください．
- 本メモは法的助言ではありません．重要な公開判断の前に，必要に応じて専門家へご相談ください．
